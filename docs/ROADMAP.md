# 🗺️ Roadmap — TaskManager

## Visão Geral

| Fase | Nome | Status | Descrição |
|------|------|--------|-----------|
| 1 | MVP | ✅ Concluído | Auth JWT + CRUD de tarefas + UI básica |
| 2 | UX & Filtros | ✅ Concluído | Filtros, prioridade, status, responsivo |
| 3 | Deploy | 📋 Planejado | Vercel (frontend) + Railway/Render (backend) |

## Fase 1 — MVP (Concluído)

- [x] Backend Express + SQLite
- [x] Registro e Login com JWT
- [x] Middleware de autenticação
- [x] CRUD de tarefas (por usuário)
- [x] Frontend React + Vite + Tailwind
- [x] Páginas Login / Register / Dashboard
- [x] Context de autenticação

## Fase 2 — UX & Filtros (Concluído)

- [x] Status (Pendente / Em Progresso / Concluída)
- [x] Prioridade (Baixa / Média / Alta)
- [x] Filtros no Dashboard
- [x] Layout responsivo
- [x] Feedback visual de ações

## Fase 3 — Deploy

- [ ] Backend no Railway ou Render
- [ ] Frontend no Vercel
- [ ] Variáveis de ambiente de produção
- [ ] CORS configurado
- [ ] README de deploy

- [ ] Tags / categorias

- [ ] Dark mode
